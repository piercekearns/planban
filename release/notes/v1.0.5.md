# Planban v1.0.5

Planban 1.0.5 makes bug feedback agent-led, evidence-backed, and easier for users to submit.

## Added

- Feedback intent can route into the Planban feedback workflow without requiring the user to know a special command.
- The agent infers available reproduction details from conversation and workspace context, performs bounded read-only diagnostics, and searches open and closed issues and pull requests for related work.
- Reports retain unknown fields without blocking submission when details cannot reasonably be recovered.
- The feedback workflow gives a directed recommendation to comment on an existing issue or file a new issue based on its duplicate search.

## Pull request eligibility

- A fix PR is recommended only when the reporting user's agent has already implemented a concrete fix and verified it locally.
- Hypotheses, workarounds, suggested edits, and unverified patches remain issue reports rather than PR candidates.
- Issue and pull request templates now capture agent investigation, environment evidence, verification, and remaining uncertainty.

## Verification

- Added regression tests for feedback routing and the verified-local-fix eligibility boundary.
- Verified typechecking, the complete public test suite, production build, dependency audit, and an independent forward test of the installed skill behavior.
