# Planban v1.0.3

Planban 1.0.3 is a cold-launch follow-up to the browser-boundary reliability patch.

## Fixed

- Restored the default `~/.planban` launch-log path when `PLANBAN_HOME` is unset.
- Prevented a stopped Planban service from failing before it could return a verified board URL.
- Retained the bounded optional Codex browser adapter and verified-URL fallback from 1.0.2.

## Verification

- Added regression coverage for default cold-launch log-path resolution.
- Verified launcher tests, typechecking, production build, cold service startup, and current Codex in-app browser opening.
