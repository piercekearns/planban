# Planban v1.0.2

Planban 1.0.2 is a browser-boundary reliability patch.

## Fixed

- Made MCP and launcher service health plus canonical URL verification the authoritative launch result.
- Isolated Codex-specific Browser runtime discovery and navigation behind a bounded optional presentation adapter.
- Preserved the verified board URL when the Codex Browser runtime is unavailable, cannot initialize, cannot create or navigate a tab, or times out.
- Added structured `service-url` and `browser-presentation` diagnostics so core launch failures are distinguishable from embedded-browser degradation.
- Updated `/pb` and `/planban` guidance to return a concise clickable verified URL whenever automatic in-app opening is unavailable or fails.
- Kept automatic in-app opening when the current supported Browser runtime is available.

## Verification

- Added regression coverage for browser unavailable, Browser setup failure, tab/navigation failure, and normal automatic opening.
- Verified the public launcher, MCP surface, production build, installed-cache runtime, isolated install, and update preflight paths.
