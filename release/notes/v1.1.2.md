# Planban v1.1.2

Planban v1.1.2 is a compatibility and launch-reliability patch.

## Fixes

- Recover legacy writer versions when retired review state is explicitly `null` or hierarchy ranks can be reconstructed deterministically. Current writer-version corruption still fails closed.
- Verify that a board can be parsed before a launcher reports its URL as healthy. An HTML fallback or unreadable board no longer passes readiness checks.
- Use `127.0.0.1` for local Planban URLs so Codex's in-app browser does not depend on environment-specific `localhost` resolution.
- Strengthen release upgrade rehearsal by creating a card before update, then reading and mutating it with the candidate release.

## Verification

The release preflight covers version consistency, install-script policy, typecheck, the complete test suite, dependency audit, production build, HTTP behavior, MCP behavior, cached-plugin launch and stale-server repair. Release readiness additionally rehearses a real v1.1.1 to v1.1.2 upgrade and verifies that the previous board remains readable and writable.
