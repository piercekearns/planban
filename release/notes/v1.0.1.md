# Planban v1.0.1

Planban 1.0.1 is a reliability release for opening and running local boards from Codex.

## Fixed

- Updated the in-app browser opener to use the Agent returned by the current Browser runtime contract.
- Reused a distinct persistent in-app browser binding without replacing external browser bindings or creating duplicate tabs.
- Resolved installed runtime roots from adjacent plugin `.mcp.json` metadata without requiring `PLANBAN_REPO_ROOT` or a marketplace symlink.
- Limited filesystem watching to live registry and repository state while excluding version-history trees that could exhaust file descriptors.
- Handled asynchronous watcher errors without terminating the Planban server.
- Strengthened detached server startup with repeated API and web-surface health checks, captured logs, safer PID publication, and clearer timeout or early-exit errors.
- Repaired stale Planban listeners whose API responds while their web bundle is unavailable.

## Verification

- Added regression coverage for the returned-Agent Browser contract and safe in-app browser reuse.
- Added low-file-descriptor, large-history, and asynchronous watcher-error tests.
- Added realistic installed-cache launcher verification without a masking marketplace symlink.
- Verified the generated public release, MCP surface, detached launcher, and stale-server repair flow.
