# Planban v1.1.4

Planban v1.1.4 prepares future marketplace updates to feel far lighter. It reuses installed dependencies only after proving they remain compatible and healthy, strengthens Windows command execution, and gives update confirmation the same calm treatment as Update Available.

## Faster Future Updates

- Git marketplace updates can preserve the existing dependency installation while Codex refreshes Planban's source, then restore it after verifying the dependency fingerprint, platform, architecture, Node.js runtime, required modules, and dependency tree.
- Any mismatch, missing input, failed verification, or disabled reuse selects the existing clean-install path. A failed marketplace refresh restores the previous dependencies when possible.
- Local clone updates are unchanged.

The v1.1.3-to-v1.1.4 installation still runs through the older v1.1.3 updater, so that update will not receive the speed improvement. Once v1.1.4 is installed, later marketplace updates with compatible dependencies can use the faster path. Updates that change dependencies will take the normal clean-install path.

## Stronger Windows Updates

- Planban now invokes the npm-installed Codex, npm, and npx command shims through the correct Windows command boundary.
- Preflight, update execution, marketplace refresh, release rehearsal, and installed-runtime verification share the same bounded behavior.
- Native commands and non-Windows execution remain direct.

## Calmer Confirmation

- The Update now action now matches the accepted Update Available treatment with a solid accent fill, white text, and no decorative icon.
- Existing modal dimensions, progress feedback, and error handling remain unchanged.

## Verification

The exact release candidate passed release preflight, the complete Windows suite and build, and updater compatibility on Node.js 22.12 and 24 for Windows and Linux. Five clean-install and five verified-reuse marketplace updates passed on Windows, Linux, and macOS; every sample installed the exact candidate and preserved its Board.

Median confirmation-to-readable-Board time improved by 95.7 percent on the hosted Windows runner, 61.2 percent on Linux, and 50.9 percent on macOS. These paired results demonstrate a material relative improvement, not a fixed duration promise for every machine or network.

The release changes no Board storage schema, requires no migration or new environment variable, and keeps `PLANBAN_DISABLE_DEPENDENCY_REUSE=1` as an emergency switch to force the existing clean-install path.
