# Planban v1.1.1

Planban v1.1.1 is a reliability and usability patch for the public v1.1 release.

## Improvements

- Use polling for the small Planban planning-state directory on Windows, avoiding native watcher permission failures that can terminate the local service.
- Scroll overflowing Group names on hover or keyboard focus while preserving the reduced-motion ellipsis.
- Keep the automatic first-run tour tile on the demo onboarding surface instead of covering established project boards when the local server origin or port changes.
- Finish successful agent-made Planban creation and material planning changes with one verified clickable Board handoff.

## Verification

The release preflight covers version consistency, install-script policy, typecheck, the complete test suite, dependency audit, production build, HTTP behavior, MCP behavior, cached-plugin launch and stale-server repair. Release readiness additionally rehearses a real v1.1.0 to v1.1.1 upgrade while preserving the existing board and checking installed guidance.
